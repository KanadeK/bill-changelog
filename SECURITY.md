# Security policy

## Supported versions

Security fixes are provided for the latest released minor version.

## Report privately

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue with
an exploit, credential, personal statement, or account data.

Include the affected version, input format, minimal fictional reproducer, impact, and any proposed
mitigation. You should receive an acknowledgement within seven days.

## Scope notes

False-positive redaction, HTML escaping, path handling, archive integrity, parser denial of service,
and dependency vulnerabilities are in scope. Disputes about whether a real provider charge is
authorized are not software vulnerabilities.
