# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic
versioning.

## [0.1.0] - 2026-08-08

### Added

- Local TXT, CSV, JSON, EML, and text-PDF capture with line/page evidence.
- Deterministic alias and fuzzy line-item matching.
- Added, removed, renamed, amount, category, and cadence change detection.
- Monthly/annualized impact and configurable severity thresholds.
- Default identifier masking and HTML injection protection.
- JSON, CSV, Markdown support pack, self-contained HTML, and SHA-256 manifest outputs.
- `capture`, `compare`, `verify`, `demo`, and `doctor` commands.
- Fictional examples, cross-platform CI, CodeQL, deterministic release packaging, and repair docs.
